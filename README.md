# Потрачено — учёт расходов в Telegram

Мини-апп и бот: пользователь вносит доходы, фотографирует чеки или вписывает траты, нейросеть раскладывает их по категориям, а приложение показывает, сколько осталось в этом месяце. 1-го числа бот присылает разбор.

## Что умеет

- **Остаток месяца**: доходы минус все расходы. На главном экране — остаток, шкала «потрачено X из Y», доходы и расходы отдельно, прогноз на конец месяца с учётом регулярных платежей, которые ещё впереди.
- **Регулярные доходы и расходы**: при добавлении зарплаты, аренды, страховки или подписки можно включить «Повторять каждый месяц» и выбрать число. Дальше запись появляется сама в нужный день. Если в месяце нет такого числа (31-е в ноябре), запись встаёт на последний день. Список регулярных платежей можно открыть в настройках или в блоке «Ожидается в этом месяце»: там их можно поменять, поставить на паузу или отключить. Если у регулярной записи поменялась сумма, приложение спросит, менять ли её и в следующих месяцах.
- **Фото чека** в приложении или прямо в чате с ботом. Нейросеть (Claude) читает позиции и делит чек по категориям: в одном чеке из супермаркета продукты, бытовая химия и корм для кота окажутся в разных статьях. Перед сохранением в приложении можно поправить категории и суммы.
- **Ручной ввод**: в приложении или сообщением боту — `4,50 кофе`, `€12 обед`, `120 USD отель`, `1 200 руб такси`. Доход — с плюсом: `+2500 зарплата`. Категорию подставляют правила по ключевым словам, а если не сработали — нейросеть.
- **Несколько валют**: каждая трата хранится в своей валюте и пересчитывается в основную по курсу дня. Основную валюту пользователь выбирает при первом запуске.
- **Итоги месяца**: на экране — сумма, сравнение с прошлым месяцем, график по дням, категории с долями, история по дням. 1-го числа бот присылает сводку: доходы, расходы, остаток, главные категории, что выросло, что сократилось, самый дорогой день. Команда `/report` — сводка за текущий месяц в любой момент.
- **Для открытого продукта**: каждый пользователь видит только свои данные (проверяется подпись Telegram), лимит распознаваний чеков в месяц, выгрузка всех трат в CSV, удаление всех своих данных одной кнопкой, русский и английский интерфейс. Фото чеков не хранятся.

## Что понадобится

1. **Компьютер с Node.js** — скачайте LTS-версию с nodejs.org и установите.
2. **Бот в Telegram**. Напишите @BotFather → `/newbot` → придумайте имя и адрес → получите токен.
3. **Аккаунт Cloudflare** (бесплатный) на dash.cloudflare.com. Там будет жить сервер и база.
4. **Ключ Anthropic API** для распознавания чеков: console.anthropic.com → API Keys → Create Key. Пополните баланс на $5–10: распознавание одного чека обходится примерно в доли цента.

## Публикация

Приложение публикуется автоматически из GitHub: каждое изменение в ветке `main` за 1–2 минуты разворачивается в Cloudflare (GitHub → вкладка **Actions** → Deploy). Там же можно перезапустить публикацию вручную: **Run workflow**.

Сценарий сам создаёт базу при первом запуске, применяет изменения её структуры, публикует приложение, сохраняет ключи и подключает бота.

Нужны четыре секрета в репозитории (Settings → Secrets and variables → Actions):

| Секрет | Откуда взять |
|---|---|
| `CLOUDFLARE_API_TOKEN` | Cloudflare → My Profile → API Tokens → Create Token → шаблон **Edit Cloudflare Workers**, добавить право **Account · D1 · Edit** |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare → Workers & Pages → справа «Account ID» |
| `BOT_TOKEN` | @BotFather |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys |

Чтобы сменить ключ (например, перевыпустили токен бота), обновите секрет и перезапустите публикацию.

**Желательно ещё:** в @BotFather → `/mybots` → ваш бот → Bot Settings → Configure Mini App → Enable Mini App и укажите адрес приложения `https://potracheno.…workers.dev`. Тогда приложение будет открываться по прямой ссылке `t.me/имя_бота/app`.

### Публикация со своего компьютера (запасной вариант)

```
npm install
npm run setup     # первый раз: база, публикация, ключи, бот
npm run deploy    # дальше: обновление
```

## Настройки

В `wrangler.toml`, раздел `[vars]`:

| Параметр | Что значит | Сейчас |
|---|---|---|
| `FREE_SCANS_PER_MONTH` | сколько чеков в месяц может распознать один пользователь | 60 |
| `FREE_SUGGESTS_PER_MONTH` | сколько раз в месяц нейросеть подсказывает категорию для ручного ввода | 400 |
| `CLAUDE_MODEL` | модель для распознавания | claude-haiku-5-5 |

**Если захотите сменить название.** Поменяйте `<title>` в `public/index.html` и тексты в `src/index.js` (блок `BOT_TEXT`). Имя бота меняется в @BotFather.

**Категории** — в `src/categories.js`. Подписи и эмодзи можно менять свободно, а `id` существующих категорий лучше не трогать: они записаны в базе.

## Сколько это стоит

- **Cloudflare**: бесплатный тариф покрывает 100 тыс. запросов в день и базу до 5 ГБ. Этого хватит на тысячи активных пользователей. При большем росте — тариф Workers Paid за $5 в месяц, он же снимает лимит на рассылку итогов (на бесплатном — около 5–6 тыс. отчётов за двое суток).
- **Anthropic**: оплата за распознанные чеки. Лимит в `FREE_SCANS_PER_MONTH` ограничивает расход на одного пользователя.

## Устройство

```
public/            интерфейс мини-аппа (HTML, CSS, JS без сборки), цвета берутся из темы Telegram
src/index.js       API приложения, бот, админка, расписание (регулярные платежи — каждый час, отчёты — 1–2 числа)
src/ai.js          распознавание чеков и подсказка категорий через Claude API
src/report.js      сводка за месяц и ежемесячная рассылка
src/recurring.js   регулярные платежи: создание записей в нужный день, прогноз
src/rates.js       курсы валют (open.er-api.com, раз в день, с запасным вариантом)
src/auth.js        проверка подписи Telegram
migrations/        структура базы
scripts/setup.mjs  установка с компьютера
scripts/ci-deploy.mjs  публикация из GitHub Actions
.github/workflows/ публикация при каждом изменении
```

Адреса для владельца (ключ администратора при публикации из GitHub вычисляется из токена бота — спросите Claude или см. `scripts/ci-deploy.mjs`; при установке с компьютера он в файле `.admin-key`):

- `/admin/stats?key=…` — пользователи, активные за месяц, траты, распознанные чеки.
- `/admin/setup?key=…` — заново подключить бота (если сменился адрес или токен).

## Локальная проверка без Telegram

Создайте файл `.dev.vars`:

```
DEV_MODE=1
MOCK_AI=1
BOT_TOKEN=000:dev
ADMIN_KEY=dev
```

Затем выполните `npx wrangler d1 migrations apply potracheno --local` и `npm run dev`. Откройте http://localhost:8787. Вместо нейросети будет тестовый чек.
